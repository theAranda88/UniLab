# Documentación de diseño — Eduinova (UniLab)

Rediseño visual del frontend `unilab_front` a partir del maquetado de Claude Design («Eduinova Prototipo publicable.html»).

> **Regla del proyecto: solo diseño.** Se cambian estilos y estructura de marcado; no se toca lógica, rutas, servicios, modelos, bindings ni claves i18n, y no se crean pantallas ni funciones que no existan en el código.

| Documento | Para qué sirve |
|---|---|
| [01-fundamentos.md](01-fundamentos.md) | Colores, tipografía, espaciado, radios, sombras, movimiento, breakpoints, iconografía, accesibilidad |
| [02-componentes.md](02-componentes.md) | Catálogo de los 24 componentes reutilizables: aspecto, variantes, estados, dónde se usan y qué existe hoy |
| [03-estructura-frontend.md](03-estructura-frontend.md) | Diagnóstico, arquitectura de estilos, mapeo de tokens actuales → nuevos, mapa pantalla → archivos, fases |
| [04-pautas-ux.md](04-pautas-ux.md) | Principios, reglas transversales, recorridos por rol, notas por pantalla, móvil y checklist |
| [export/INDICE.md](export/INDICE.md) | Las 26 pantallas en alcance con ruta, rol y componentes |
| [export/README.md](export/README.md) | Reglas de «solo diseño» y flujo de trabajo con Claude Design |

Resumen en una línea: **azul `#053686` para la identidad, crema `#FFFDF5` para la página, blanco para las superficies, negro `#1E1E1E` para el texto y amarillo `#E3C924` solo para señalar; todo en Nunito con íconos Tabler.**
